# 🧮 Mac Calculator - Python Tkinter Project
### MCA Department - Python Lab Work

This is a simple and elegant calculator application designed with Mac OS style, developed as part of our MCA curriculum using Python Tkinter.

### 🌟 Features of this Calculator
* ➕ Performs Addition, Subtraction, Multiplication, Division
* 💻 Beautiful Mac Style Interface
* ⌨️ Works with both Mouse and Keyboard
* ⚠️ Shows Error Message for Invalid Input
* 🔄 AC Button to Clear All

### 🔧 Used Technologies
* Python Programming Language
* Tkinter for GUI Design
